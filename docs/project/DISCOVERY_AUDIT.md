## Refactor scope

- Keep live counts, public announcements, Lost & Found, the existing `/clubs` search, and club profile/join flows.
- Share the existing club-health calculation rather than creating another activity formula.
- Fix the landing upcoming-event relation filter so events from inactive clubs are not shown publicly.
- Add only persisted interest taxonomy and associations, URL-validated discovery controls, explicit public DTOs, and responsive presentation for the new discovery area.

## Known data constraints

- “Verified” means the club is active and has completed the existing review (`reviewedAt`); there is no independent verification workflow.
- There is no public contact field. The landing page will omit contact details.
- A leader appears only where an approved member has an explicitly assigned official role containing “chairperson”.
- The taxonomy can be populated immediately, but club matches become meaningful after club admins assign interests.
